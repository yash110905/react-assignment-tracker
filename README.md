# 📚 React Assignment Tracker

A simple and user-friendly **Assignment Tracker application** built using **React + Vite**.
This application helps students organize assignments by adding due dates, setting priorities, searching assignments, and tracking completion status.

This project was created for the **COMP 2068 React Tutorial Presentation**.

# 🚀 Live Demo

https://react-assignment-tracker-lyart.vercel.app/

---

# 📌 Project Description

The React Assignment Tracker allows users to:

- Create new assignments
- Add due dates
- Select assignment priority levels
- Mark assignments as completed
- Delete assignments
- Search assignments
- Filter assignments by status
- Save assignments using browser Local Storage

The goal of this project is to demonstrate the fundamentals of React including components, state management, event handling, and data persistence.

# ✨ Features

## Assignment Management

✅ Add new assignments
✅ Delete assignments
✅ Mark assignments as completed
✅ View assignment details


## Priority System

Assignments can have different priority levels:

🔴 High Priority
🟠 Medium Priority
🟢 Low Priority


## Search & Filtering

Users can:

- Search assignments by name
- View all assignments
- View completed assignments
- View pending assignments


## Data Storage

The application uses:

- Browser Local Storage

This allows assignments to remain saved even after refreshing the page.
